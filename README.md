# La Boutique della Bellezza

Sito vetrina per parrucchiere uomo/donna con catalogo cosmetici, realizzato con Next.js, TypeScript e componenti UI
moderni.

## Obiettivo

Il progetto presenta una presenza digitale chiara per un business beauty locale: servizi, proposta commerciale, catalogo
prodotti e comunicazione orientata alla conversione.

## Stack

| Area  | Tecnologie                                                  |
| ----- | ----------------------------------------------------------- |
| App   | Next.js, React, TypeScript                                  |
| UI    | Radix UI, Tailwind CSS, Lucide React                        |
| Forms | React Hook Form, Zod                                        |
| UX    | componenti accessibili, layout responsive, microinterazioni |

## Avvio rapido

```bash
npm install
npm run dev
```

Apri `http://localhost:3000` nel browser.

## Script

```bash
npm run dev
npm run build
npm run lint
npm run start
```

## Note di manutenzione

- Mantenere testi e immagini coerenti con il brand locale.
- Verificare sempre responsive layout prima del deploy.
- Aggiornare catalogo e servizi da una sola fonte dati quando possibile.
